# GetGBS!

A Korean science-school-themed fork of [GetMIT](https://github.com/mitchgu/GetMIT) by Mitchell Gu. GetMIT is a clone of [2048](http://gabrielecirulli.github.io/2048/) by Gabriele Cirulli and [1024](https://play.google.com/store/apps/details?id=com.veewo.a1024), based on [Saming's 2048](http://saming.fr/p/2048/).

Inspired by Get Caltech! by Naveen Arun. Combine the school tiles to reach 경기북과학고등학교 (2048), then keep playing to find the KAIST easter egg. The tile order is not a ranking.

[Play it here!](https://eunhosode.github.io/GetGBS/)
